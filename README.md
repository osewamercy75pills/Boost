# Boost Bot ⚡

A fun Telegram bot that gives virtual boost points daily with streaks, levels, and leaderboards.

## Features
- ⚡ Daily boost claims
- 🔥 Streak multipliers
- 🏅 Level system (Starter → Legendary)
- 🏆 Leaderboard competition
- 📊 Personal statistics

## Commands
- `/start` - Main menu
- `/boost` - Claim daily boost
- `/stats` - View your stats
- `/leaderboard` - View top users
- `/help` - Help menu

## Deployment
Deployed on Railway with GitHub integration.

## Tech Stack
- Python 3.11+
- pyTelegramBotAPI
- Railway
